## VOFA 设温和输出

使用原板载 USB 串口，115200 / 8N1，文本/ASCII 发送，关闭 HEX。不需要新增接线；FPGA PC RX 为 M17，PC TX 为 L17，连接板载 CH340。

直接发送整数或最多 3 位小数，例如 `45`、`45.125`。设定范围 **10.000～80.000℃**：`5` 自动设为 10.000℃，`90` 自动设为 80.000℃。

推荐发送尾部添加 LF 或 CRLF，收到换行立即接受。没有换行时，最后一个字符后约 50 ms 接受，应一次性发送完整数字。支持正负号及首尾空格；错误文本、科学计数法、超过 3 位小数及 UART 帧错误整条忽略。

```text
T=+0020.600C,SP=+0040.000C,U=-080.0%,S=R,F=0
```

T 是补偿后的测量温度，SP 是当前实际目标，U 是实际占空比（正制冷、负加热）。S=W 等待、R 运行、F 故障。F=0 正常、1 数据超时、2 温度超窗、3 ADC 故障、4 AO/电阻无效。故障期间 T 可能保留旧值。

修改目标会清除 PID 历史积分/微分状态，保留原占空比斜率和换向死区。故障不会被设温命令清除，需排查后按 KEY1 复位。上电/KEY1 复位后目标恢复 40.000℃，不保存到非易失存储。

## +1.997℃温度补偿

用户提供参考室温 20.600℃、原读数 18.603℃，因此：

```text
修正温度 = 原换算温度 + 1.997℃
18.603℃ + 1.997℃ = 20.600℃
```

顶层参数 `TEMP_OFFSET_MDEG=1997`，传入温度换算模块的 `OFFSET_MDEG`。补偿后的温度统一用于串口、PID 和温度窗口判断，SP 本身不加补偿。固定偏移适用于所有有效测温样本，不改变 ADC 电压和电阻读数，不会把无效数据变成有效数据。

这是单点固定零点补偿，尚未校准整个量程的增益误差。0.001℃是计算/显示分辨率，不代表整套探头和模拟模块已达到 0.001℃绝对精度。

## 传感器换算与接线

LZ_TD210 使用 PT1000，AO 接 ADS1263 模块 A0（P1.2），模块和 ZYNQ 共地。温度模块保留原供电和探头接法，TXD/RXD 不再作为反馈。ADC ACM 外部悬空，由原驱动内部 VBIAS 驱动至 AVDD/2。

手册公式（R 单位 Ω、AO 单位 V、T 单位 ℃）：

```text
R = (AO - 2.5) / (4.2933 × 0.000250)
803.063 < R ≤ 1385.055: T = 9.962e-6 × R² + 0.2359 × R - 245.9
1385.055 < R < 2120.515: T = 1.161e-5 × R² + 0.2312 × R - 242.5
修正后的 T = round(T × 1000) / 1000 + 1.997
```

## 控制参数与保护

ADC 5 SPS，PID/串口报告周期 500 ms；PWM 1 kHz，双向最大 80%，每 PWM 周期变化最多 0.2%，换向关闭至少 20 ms。PID 增益（Q8）保留 2560/13/512，内部温度单位缩放保持原增益含义。

连续 3 个有效温度样本后允许驱动；ADC/AO 错误、温度超窗、样本超时均停机并锁存。应用测温窗口仍是 **-20.000～80.000℃**，按补偿后的温度判断。设为 80.000℃时，若实测超过 80℃，包括过冲/噪声，仍会触发 F=2 停机。
